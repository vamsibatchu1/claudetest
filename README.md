# Text Tetris

A unique twist on the classic Tetris game where instead of colored blocks, you arrange falling text blocks! Built with React and Framer Motion.

## Features

- **Text-based blocks**: Words and phrases fall instead of traditional Tetris pieces
- **Smooth animations**: Powered by Framer Motion
- **Mobile-friendly**: Touch controls optimized for mobile devices
- **Responsive design**: Works on all screen sizes
- **Progressive difficulty**: Speed increases with each level
- **Score tracking**: Points, lines cleared, and level progression

## How to Play

- **Desktop**: Use arrow keys to move blocks, spacebar to rotate, Enter to drop instantly
- **Mobile**: Use the touch controls at the bottom of the screen
- **Objective**: Arrange falling text blocks to complete horizontal lines
- **Scoring**: Clear lines to increase your score and level up

## Controls

### Keyboard
- `←` / `→` - Move left/right
- `↓` - Move down faster
- `↑` / `Space` - Rotate piece
- `Enter` - Drop instantly
- `P` / `Esc` - Pause game

### Touch
- Use the on-screen buttons for all controls
- Optimized for touch with no-delay response

## Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
